# Factory Slasher

2D 핵앤슬래시 / 공장 게임 프로토타입의 Windows 테스트 빌드입니다.
Windows playtest builds of a 2D hack-and-slash / factory game prototype.

[모든 버전 / All releases](https://github.com/skh1995328/factory-slasher-releases/releases)

## 실행 방법 / How to play

1. 릴리스의 `ver0.0.5.zip`을 다운로드하세요. / Download `ver0.0.5.zip` from the release.
2. 압축을 모두 풀어 주세요. / Extract the entire ZIP.
3. `ver0.0.5.exe`를 실행하세요. / Run `ver0.0.5.exe`.

`ver0.0.5.pck`와 `factory_core.windows.template_release.x86_64.dll`은 EXE와 같은 폴더에 있어야 합니다. Windows x64용이며 Godot 설치는 필요하지 않습니다.
Keep `ver0.0.5.pck` and `factory_core.windows.template_release.x86_64.dll` in the same folder as the EXE. Requires Windows x64; Godot installation is not required.

이 저장소는 배포 파일과 실행 안내용입니다.
This repository contains downloads and launch instructions.
